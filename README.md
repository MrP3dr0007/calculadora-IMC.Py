# Calculadora de IMC em Python
 Esse é um projeto que desenvolvi em Python para praticar lógica de programação e alguns conceitos básicos da linguagem.
 A calculadora recebe alguns dados do usuário, como nome, idade, peso e altura, calcula o Índice de Massa Corporal(IMC) 
 e mostra a classificação do resultado.

## Funcionalidades
 - Entrada de dados
 - Operações matemáticas
 - Variáveis
 - Estruturas condicionais
 - Exibição de resultados

## Tecnologias utilizadas
 - Python
 - VS Code

## Objetivo
 Desenvolver um projeto simples para colocar em prática o que estou aprendendo em Python, lógica de programação 
 e evoluir meus conhecimentos em programação.
